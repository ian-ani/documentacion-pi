# 1. Presentación

Sistema que permite digitalizar y simplificar la solicitud y gestión de los días moscosos del profesorado. Dicho sistema permitirá al profesorado consultar los días disponibles, realizar solicitudes y comprobar su estado mediante una aplicación móvil y web. Por otro lado, el equipo directivo podrá revisar las solicitudes y aprobarlas o rechazarlas, mientras que el personal gestor podrá importar los calendarios escolares mediante un programa de escritorio.
El objetivo principal es centralizar este proceso en una única solución, reduciendo el trabajo manual y facilitando la comunicación entre el profesorado y el equipo directivo.

Esta documentación ha sido publicada mediante GitHub Pages.
